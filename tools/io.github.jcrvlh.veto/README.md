# Veto

Mini-jogo de mesa para o **KIT**: uma pessoa segura o aparelho, vê a **palavra-alvo** grande no centro e a **descreve** para o time adivinhar — sem dizer a palavra nem nenhuma das **proibidas** listadas abaixo dela (nem pedaços ou traduções).

Acertou, toca no **JOINHA (👍)** e cai a próxima carta; falou uma proibida, toca no **DISLIKE (👎)** e a **cigarra** dispara. Quando o **TEMPO** acaba, o KIT mostra quantas você acertou!

## Como jogar

1. **Ajuste:** Escolha o tempo da vez (`60S`, `90S`, `120S` ou `OFF`), quantas proibidas exibir (`2` ou `3`), o baralho (`FÁCIL` ou `TUDO`) e a quantidade de pulos (`1`, `2`, `3`, `LIVRES` ou `OFF`).
2. **Jogo:** Toque em `COMEÇAR`. Descreva a palavra amarela para seu time sem falar as proibidas marcadas com o quadradinho vermelho.
3. Ao fim do tempo, toque na tela para silenciar o alarme e conferir os pontos com a mesa. Toque em `PASSAR A VEZ` para passar o KIT para a próxima pessoa.
